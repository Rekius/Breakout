# Breakout

Mi primer juego en Unity 2D: un clon de Breakout hecho para aprender.

## Características
- Niveles definidos por texto (editables desde el Inspector)
- Ladrillos con distinta resistencia
- Sistema de vidas y puntaje
- Ángulo de rebote según dónde pega la bola en la paleta
- Sonidos con variación aleatoria de pitch
- Partículas al romper ladrillos

## Controles
- **A / D** o **flechas**: mover la paleta
- **Espacio**: lanzar la bola

## Hecho con
- Unity (2D) y C#
- New Input System
